## 🔄 How to Use / Customize

### 1. **Change Content**
Edit `index.html` to update:
- Main headline and messaging
- Problem statement flow
- Curriculum items
- Benefits list
- Testimonials
- CTAs

### 2. **Update Form**
Replace the Zohopublic form URL in:
- Hero section form
- Contact section form
- Update both instances to your unique form URL

### 3. **Customize Colors**
In `style.css`, change `:root` variable:
```css
:root {
    --primary-color: #2355cf; /* Change this to your color */
}
```

### 4. **Add Images**
Reference images in the `icf-coach-certification` folder or create new image folder for HR Leaders specific assets

### 5. **Update Footer Links**
Add company links, privacy policy, etc. in the footer
